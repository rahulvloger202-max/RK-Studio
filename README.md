
# PrimX IDE 🚀

Ek powerful offline Android IDE jisme C++ aur Java ka native compiler inbuilt hai. Bina internet ke apne phone par code likho aur compile karo!

## 🔥 Key Features
- 100% Offline Java & C++ Compilation
- Native PRoot Linux Shell Engine
- GitHub Cloud Sync & Actions Integration
- Fast, secure aur smooth UI
